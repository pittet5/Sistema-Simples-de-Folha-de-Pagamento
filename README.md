# 💻 Simplei Gerencial
Esse projeto é um exemplo de sistema de folha de pagamento que serve de base para outros desenvolvedores que queiram criar o seu.

# 💡Importante
Algumas considerações antes de prosseguir com a leitura do projeto
* Esse projeto possui um CLI próprio criado para sistema de entrada
* Ele roda localmente e possui apenas exemplos de como rodar um em um servidor dedicado
* Este projeto foi feito como atividade para um curso superior.

# ❓Perguntas Comuns
Antes de prosseguir aqui está uma lista de perguntas comuns que podem ser respondidas:

* Este projeto server como uma **BASE** para outros projetos, portanto utilize-o como ponto de entrada para entender documentação, estruturação e desenvolvimento de seus próprios sistemas
* Sinta-se livre para utilização acadêmica e pessoal desse projeto
* Esse projeto foi desenvolvido por **Pedro "pittet" Henrique**
* Outros documentos mais aprofundados sobre o projeto podem ser encontrado na pasta **docs**

# ⬇️ Instalação
Você pode instalar esse sistema utilizando o pip com o código abaixo no terminal de sua IDE:
> pip install my-package
Também é necessário instalar o Python 3 na sua máquina
