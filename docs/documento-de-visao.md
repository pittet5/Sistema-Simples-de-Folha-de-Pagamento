# 2.  Objetivo
Este projeto tem como objetivo demonstrar um sistema de folha de pagamento de nome fictício "Simplei Gerencial" para servir de base para desenvolvedores que busquem criar seu próprio.
# 3. Escopo
## 3.1 Prazo
Este projeto possui duas entregas, uma do planejamento, modelagem e garantia de qualidade do projeto, no dia 30 de outubro de 2026. A segunda de implementação, testes e homologação no dia 1 de dezembro de 2026
## 3.2 Meta
Este projeto tem como meta ser base para outros desenvolvedores iniciantes entenderem como funciona a estruturação, criação e desenvolvimento de um sistema de folha de pagamento.
## 3.3 Entregas
* Documento de visão de projeto
* Especificação de Requisitos de Software (ERS)
* Modelagem UML
* Documentos de Arquitetura
* Plano de Garantia da Qualidade (PGQ)
* Plano de Testes
* Especificação de Casos de Testes
* Planejamento do Projeto
* Repositório do Projeto
# 4 Premissas
* O projeto será desenvolvido no período de 1 semestre letivo (113 dias)
* Durante o desenvolvimento do projeto o professor responsável acompanhará e orientará os alunos
* O desenvolvimento do projeto poderá ser feito durante o período de aula utilizando os computadores da instituição de ensino ou com equipamento próprio dos alunos
# 5 Restrições
* O grupo do projeto será composto de até 4 alunos
* O projeto deverá ser feito sob as especificações listadas nos Modelos de Artefatos Obrigatórios
# 6 Benefícios Esperados
Este projeto tem como benefício esperado o desenvolvimento acadêmico do(s) aluno(s) participantes bem como qualquer desenvolvedor que deseja entender como desenvolver projetos.
